# GlassWall

The DeskGlass village sim as an Android live wallpaper. Villagers hunt, gather and build on their own, and the
settlement grows from a camp through huts, a village and a town into a city. Optional local-model brain
(Ollama over Tailscale); without one the villagers use built-in rules.

Install the APK from the latest release, open GlassWall, tap **Set as wallpaper**. After that it updates itself.
